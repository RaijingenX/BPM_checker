A beginner-friendly Python project that checks whether a person's heart rate (BPM - Beats Per Minute) falls within a healthy range based on different age groups.

---

## 📖 About

BPM Checker is a simple console-based Python application designed for learning Python fundamentals.

The program:

- Accepts the user's age.
- Determines the correct age group.
- Accepts the user's heart rate (BPM).
- Displays one of three health statuses:
  - 🟢 Healthy
  - 🟡 Not Healthy
  - 🔴 Risky

This project was created to practice Python conditional statements (`if`, `elif`, `else`) and user input handling.

---

## 👥 Age Categories

| Category | Age |
|-----------|------|
| 👶 Infant | 0–6 Years |
| 🧒 Teenager | 7–17 Years |
| 👨 Adult | 18+ Years |
